## 🚀 Quick Start

```bash
# Make start script executable
chmod +x start.sh

# Start the server
./start.sh

# Open http://localhost:8000
```

## 📝 Customization

1. **Edit Content**: Modify `config.json`
2. **Change Colors**: Edit CSS variables in `styles.css`
3. **Add Images**: Place in `images/` folder
4. **Update Structure**: Modify `index.html`
